# IPTV no computador

No PC ou notebook a tela é grande e o mouse facilita a navegação. Você pode instalar o aplicativo da CorePlay para Windows ou assistir pelo navegador.

## Aplicativo para Windows

Requisito: **Windows 10 ou 11, 64 bits**.

1. Abra a [página do CorePlay para Windows](https://coreplay.vc/app/windows?utm_source=readthedocs&utm_medium=referral&utm_campaign=blog_da) e clique em **Baixar para Windows**.
2. Abra o arquivo **PlayFastSetup.exe** na pasta Downloads.
3. Se aparecer **"O Windows protegeu o computador"**, clique em **Mais informações → Executar assim mesmo**. O aviso aparece porque o instalador não vem da Microsoft Store.
4. Siga o instalador até o fim, abra o app e entre com usuário e senha.

## Outras opções

- **Navegador:** assista sem instalar nada, em Windows, Mac ou Linux.
- **Players:** IPTV Smarters e VLC aceitam login Xtream ou lista M3U.
